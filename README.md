# RentGear

Проект доступен к ознакомлению без локального запуска по ссылке https://sbendy.github.io/FrontEnd_RentGear

Веб-приложение для аренды строительной и специальной техники: каталог, оформление заявок, учётная запись клиента и админ-панель.

**Стек:** React, TypeScript, Vite, React Router.

Данные пользователей и заявок хранятся в браузере (localStorage). API эмулируется на клиенте; прогноз погоды загружается с [Open-Meteo](https://open-meteo.com/) и [7Timer](https://www.7timer.info/).

## Локальный запуск

```bash
npm install
npm run dev
```

http://localhost:5173

## Роли

| Роль | Возможности |
|------|-------------|
| Клиент | Каталог, заявки, «Мои заявки» |
| Администратор | Просмотр всех заявок, смена статуса |

Регистрация: на странице «Регистрация» выберите тип учётной записи.

## Структура

```
src/
  pages/       — экраны
  components/  — общие компоненты
  api/         — запросы к API и погоде
  mocks/       — эмуляция REST API
  context/     — авторизация
```
